## 1. 프로젝트 목표

스팀 게임 **발라트로(Balatro)**를 웹에서 원작과 같은 규칙으로 플레이할 수 있게 만든다.
진짜 목표는 게임 자체가 아니라, **다른 사람이나 다른 AI가 문서만 읽고 이어서 작업할 수 있는 상태**다.

성공 기준
- 배포 주소에서 누구나 바로 한 판(앤티 1~8)을 플레이할 수 있다.
- 세션 한도로 작업이 끊긴 뒤, 다른 AI(Codex, Copilot 등)가 `docs/progress.md`만 읽고 2차 작업 하나를 끝낸다.

## 2. 대상 게임

| 항목 | 내용 |
|---|---|
| 원작 | Balatro (개발 LocalThunk, 배급 Playstack, 2024) |
| 장르 | 포커 족보 기반 로그라이크 덱빌딩 |
| 화면 이름 | 발라트로 |
| 가져오는 것 | 규칙, 수치, 진행 구조, 조커 효과 |
| 가져오지 않는 것 | 원작 이미지, 카드 그림, 사운드, 글꼴, 로고. 그래픽은 CSS로 직접 그린다 |

비상업 학습용 팬 프로젝트로 배포한다. 화면 하단에 원작 출처와 "비공식 팬 제작"을 표기한다.

### 2.1 원작 규칙 요약

구현자가 원작을 해보지 않았어도 이해할 수 있도록 핵심만 적는다.
아래 수치는 2026-10-21에 balatrowiki.org(Poker Hands, Blinds and Antes, Money, The Shop, Jokers 문서)와 대조해 확정했다. 난이도는 가장 쉬운 화이트 스테이크 기준이다.
원작 기본 덱(레드 덱)은 버리기 +1 보너스가 있지만, 이 프로젝트는 덱 선택이 없으므로 보너스 없는 기본값(버리기 3번)을 쓴다.

한 판의 흐름
1. 앤티(Ante) 1부터 8까지 진행한다. 앤티마다 스몰 블라인드, 빅 블라인드, 보스 블라인드 3번의 라운드가 있다.
2. 라운드마다 목표 점수가 있다. 정해진 횟수 안에 목표 점수 이상을 모으면 통과한다.
3. 통과하면 돈을 받고 상점에 들어가 조커를 산다.
4. 앤티 8 보스 블라인드를 통과하면 승리, 어느 라운드든 핸드를 다 쓰고도 목표에 못 미치면 패배.

라운드 안에서
- 52장 표준 덱에서 손패 8장을 받는다.
- 카드를 1~5장 골라 **플레이**(점수 획득, 라운드당 4번) 또는 **버리기**(점수 없이 교체, 라운드당 3번)를 한다.
- 쓴 만큼 덱에서 다시 채운다.

점수 계산
- 점수 = 칩 x 배수
- 족보마다 기본 칩과 배수가 있다. 족보를 이루는 카드(점수 카드)만 자기 칩을 더한다.
- 카드 칩: 2~10은 숫자 그대로, J/Q/K는 10, A는 11
- 그다음 조커가 왼쪽부터 순서대로 칩이나 배수를 더하거나 곱한다. 조커 순서가 결과를 바꾼다.

| 족보 | 기본 칩 | 기본 배수 |
|---|---|---|
| 하이 카드 | 5 | 1 |
| 원 페어 | 10 | 2 |
| 투 페어 | 20 | 2 |
| 트리플 | 30 | 3 |
| 스트레이트 | 30 | 4 |
| 플러시 | 35 | 4 |
| 풀 하우스 | 40 | 4 |
| 포카드 | 60 | 7 |
| 스트레이트 플러시 | 100 | 8 |

10-J-Q-K-A 스트레이트 플러시는 화면에 "로열 플러시"로 표시하지만 수치는 스트레이트 플러시와 같다.

목표 점수 (앤티 기본값, 스몰 x1, 빅 x1.5, 보스 x2)

| 앤티 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 기본 | 300 | 800 | 2000 | 5000 | 11000 | 20000 | 35000 | 50000 |

돈
- 통과 보상: 스몰 $3, 빅 $4, 보스 $5, 앤티 8 보스 $8
- 남은 핸드 1번당 $1
- 이자: 가진 돈 $5마다 $1, 최대 $5

상점
- 조커 2장이 진열된다. 리롤은 $5부터 시작해 누를 때마다 $1씩 오르고, 다음 상점에서 초기화된다.
- 조커는 최대 5장 보유. 판매하면 산 값의 절반(내림, 최소 $1)을 돌려받는다.

## 3. 기능 요구사항

### 3.1 1차 범위 (첫 배포)

| ID | 기능 | 완료 기준 |
|---|---|---|
| F1 | 덱과 손패 | 52장을 섞어 8장을 받는다. 카드를 1~5장 선택하고 해제할 수 있다. 숫자순/무늬순 정렬 버튼이 있다. |
| F2 | 족보 판정 | 2.1의 9개 족보를 판정하고, 족보에 들어간 점수 카드를 구분한다. A는 A-2-3-4-5 스트레이트에서 낮은 카드로도 쓰인다. |
| F3 | 점수 계산 | 칩 x 배수로 점수를 내고, 계산 과정(족보 기본값, 카드별 칩, 조커별 효과)을 순서대로 화면에 보여 준다. |
| F4 | 플레이와 버리기 | 라운드당 플레이 4번, 버리기 3번. 남은 횟수가 보인다. 쓴 장수만큼 다시 채운다. |
| F5 | 블라인드와 앤티 | 앤티 1~8, 블라인드 3종, 2.1의 목표 점수. 앤티 8 보스 통과 시 승리 화면, 실패 시 패배 화면과 기록(도달 앤티, 최고 한 손 점수). |
| F6 | 돈 | 2.1의 보상, 남은 핸드 보너스, 이자 규칙. 라운드 종료 화면에 항목별로 보여 준다. |
| F7 | 상점 | 조커 2장 진열, 구매, 리롤, 다음 라운드로. 돈이 부족하면 구매 버튼이 비활성화된다. |
| F8 | 조커 | 최대 5장 보유, 판매, 순서 바꾸기. 1차 조커 10종 (아래 표). |
| F9 | 최고 기록 저장 | 최고 도달 앤티, 최고 한 손 점수를 브라우저에 저장한다. |

1차 조커 10종 (모두 원작의 일반 등급, 위키와 대조 완료)

| id | 이름 | 효과 | 가격 |
|---|---|---|---|
| joker | 조커 | 배수 +4 | $2 |
| greedy_joker | 탐욕스러운 조커 | 점수 카드 중 다이아몬드 1장마다 배수 +3 | $5 |
| lusty_joker | 색욕의 조커 | 점수 카드 중 하트 1장마다 배수 +3 | $5 |
| wrathful_joker | 분노한 조커 | 점수 카드 중 스페이드 1장마다 배수 +3 | $5 |
| gluttonous_joker | 폭식하는 조커 | 점수 카드 중 클로버 1장마다 배수 +3 | $5 |
| jolly_joker | 쾌활한 조커 | 플레이한 패에 원 페어가 포함되면 배수 +8 | $3 |
| zany_joker | 엉뚱한 조커 | 플레이한 패에 트리플이 포함되면 배수 +12 | $4 |
| sly_joker | 교활한 조커 | 플레이한 패에 원 페어가 포함되면 칩 +50 | $3 |
| half_joker | 하프 조커 | 플레이한 카드가 3장 이하면 배수 +20 | $5 |
| abstract_joker | 추상적 조커 | 보유한 조커 1장마다 배수 +3 (자기 자신 포함) | $4 |

"포함"은 플레이한 카드 안에 그 족보가 들어 있으면 참이다. 예를 들어 풀 하우스, 투 페어, 페어가 섞인 플러시도 "원 페어 포함"이다.
1차 상점에는 조커만 진열한다. 원작의 타로, 행성 카드 진열 비율은 F10, F14에서 다룬다.

## 4. 비기능 요구사항

이전 프로젝트에서 생긴 문제를 요구사항으로 바꿨다.

| ID | 요구사항 | 이전 문제 |
|---|---|---|
| N1 | 게임 규칙, 화면, 저장을 파일과 폴더로 나눈다. 게임 규칙은 화면 없이 테스트할 수 있어야 한다. | 코드가 파일 하나에 다 들어 있었음 |
| N2 | 모든 구현은 `tasks.md`의 작업 단위로 진행하고, 구조 결정은 `design.md`에 남긴다. | 설계 없이 진행해 AI 결과물이 매번 달랐음 |
| N3 | 쓰지 않는 코드와 같은 일을 하는 중복 함수를 남기지 않는다. | dead code, 중복 코드 |
| N4 | 화면과 문구가 템플릿이나 AI 생성물처럼 보이지 않는다. 금지 목록은 `design.md`에 둔다. | 흔히 말하는 "AI 티" |
| N5 | 작업이 끝날 때마다 `progress.md`를 갱신한다. | 세션이 끊기면 맥락이 사라졌음 |
| N6 | 로컬 서버 없이 배포 주소에서 동작한다. 기본 배포는 Vercel, GitHub Pages로도 옮길 수 있게 정적 파일로 빌드한다. | 내 PC에서만 돌아가면 협업이 안 됨 |
| N7 | 이모지를 쓰지 않는다 (답변, 문서, 코드, 커밋, 화면 전부). | - |
| N8 | 데스크톱과 휴대폰 화면 모두에서 플레이할 수 있다. | - |
| N9 | 같은 시드를 넣으면 같은 판이 나온다. | 버그 재현과 테스트를 위해 |

## 5. 하지 않는 것

- 회원가입, 로그인, 온라인 순위표
- 서버 데이터베이스 (기록은 브라우저 저장소에만 둔다)
- 원작 에셋(이미지, 사운드, 글꼴) 복사
- 덱 종류 선택, 스테이크(난이도) 단계, 컬렉션 화면 (2차 표에도 넣지 않음. 필요해지면 요구사항부터 추가)
